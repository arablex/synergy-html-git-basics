# Учебный сайт

Небольшой учебный проект для домашнего задания по Git (курс «Frontend-разработчик»):
одна страница `index.html` с двумя картинками и стилями.

## Как открыть
1. Склонировать репозиторий: `git clone https://github.com/arablex/synergy-html-git-basics.git`
2. Открыть файл `index.html` в браузере (двойной клик или Live Server в VS Code).
Сборка и зависимости не нужны — это чистые HTML и CSS.

## Структура проекта
```
site/
├── index.html      — страница с заголовком, разделом о проекте и картинками
├── style.css       — стили страницы и картинок
├── images/
│   ├── logo.svg
│   └── landscape.svg
├── .gitignore      — служебные файлы, которые не попадают в репозиторий
└── README.md
```

## История
Работа велась в ветках `main` и `feature`: в `feature` добавлен раздел о проекте и стили картинок,
изменения влиты в `main` через pull request #1.
